# Parin Litner 7.2.0

- Added configurable PDF export for flashcard decks: printable flashcards, worksheet and quiz with optional answer key.
- PDF options include A4/A5/Letter, portrait or landscape, 1/2/4 cards per page, card images, tags, Leitner box details, difficulty/favorites, search-filtered export, and card sorting.
- Added sharing of PDF files and print / Save-as-PDF flow.
- Updated all About creator credits to Parin Mashalchian / پرین مشعلچیان.
- Android release builds now target Android 7.0+ (API 24); Android 4 compatibility APK is no longer built.
- Retained Leitner scheduling, deck/card editing, study sessions, achievements, focus timer and backup workflows.
